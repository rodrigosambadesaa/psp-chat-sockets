# Material de partida — Chat por sockets

Fuente: `Práctica Chat-20190205.zip`, conservada en Google Drive dentro del tema de sockets de PSP.

El objetivo es crear una aplicación cliente/servidor de chat que admita varios usuarios conectados al mismo tiempo. El servidor debe identificar a cada participante mediante un nombre, distribuir los mensajes entre los clientes, reflejar entradas y salidas, mantener la relación de usuarios conectados y cerrar correctamente cada sesión.

La versión de este repositorio conserva ese alcance y actualiza el protocolo y la gestión concurrente.

No existe una base de datos asociada.
